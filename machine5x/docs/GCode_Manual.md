## 概述

本系统的G代码控制功能实现了类似数控机床的程序化控制，支持：

- **自动轨迹执行**：按顺序执行多段运动轨迹
- **同步采集联动**：自动控制采集的开启/关闭
- **点云分段保存**：每段扫描数据独立保存，支持自定义文件名
- **异步文件保存**：保存操作在后台线程执行，不阻塞扫描流程
- **前瞻速度控制**：连续插补时每个点可指定独立的前瞻速度

### 文件格式

支持两种格式：

1. **标准G代码格式** (.gcode, .nc, .txt)
   ```gcode
   ; Feed: 5.0
   ; Rapid: 10.0
   ; Accel: 25.0
   N10 G00 X0 Y0 Z50         ; 快速定位 (使用Rapid速度)
   N20 M50                    ; 开始采集
   N30 G01 X100 F5.0          ; 直线扫描 (使用F指定速度)
   N40 M51                    ; 停止采集
   ```

2. **CSV简化格式** (.csv)
   ```csv
   # Program: MyScan
   # Feed: 5.0
   # Rapid: 10.0
   N,Type,X,Y,Z,Feed,Sync
   10,G00,0,0,50,,0
   20,M50,,,,,
   30,G01,100,0,10,5.0,1
   ```

## 速度参数详解

### 重要概念

| 概念 | 说明 |
|------|------|
| **进给速度 (Feed)** | 扫描时的运动速度，用于G01/G02/G03/G05 |
| **快速速度 (Rapid)** | 空行程快速移动速度，用于G00 |
| **前瞻速度** | 连续插补时每个轨迹点的目标速度，控制器据此规划速度曲线 |
| **模态速度** | F参数一旦设置，后续指令持续有效直到被新的F覆盖 |

### 速度参数来源（优先级从高到低）

1. **程序段中的F参数**（最高优先级）
   ```gcode
   G01 X100 F8.0        ; 使用F=8.0的速度
   ```

2. **G代码头部注释**（程序级默认值）
   ```gcode
   ; Feed: 5.0          ; 默认进给速度 (G01/G02/G03/G05)
   ; Rapid: 10.0        ; 快速定位速度 (G00)
   ; Accel: 25.0        ; 加速度
   ; Decel: 25.0        ; 减速度
   ```

3. **界面参数设置**（全局默认值）

### 参数说明

| 参数 | 头部关键字 | 说明 | 单位 | 默认值 |
|------|-----------|------|------|--------|
| 进给速度 | `Feed:` | G01/G02/G03/G05 默认速度 | mm/s | 5.0 |
| 快速速度 | `Rapid:` | G00 快速定位速度 | mm/s | 10.0 |
| 加速度 | `Accel:` | 运动加速度 | mm/s² | 25.0 |
| 减速度 | `Decel:` | 运动减速度 | mm/s² | 25.0 |
| S曲线 | `SRamp:` | S曲线时间比例 | % | 50 |
| 起始速度 | `LSpeed:` | 起始速度 | mm/s | 0.5 |

> **重要**：以上默认值参考控制器的 `AxisParams` 实际参数。请根据您的机械系统调整，速度过快可能导致运动失控！

### 各指令的速度规则

| 指令 | 默认速度来源 | F参数作用 | 说明 |
|------|-------------|----------|------|
| **G00** | Rapid（快速速度） | 可覆盖（但通常不用） | 空行程快速移动 |
| **G01** | Feed 或 模态F | 设置并更新模态速度 | 直线插补 |
| **G02/G03** | Feed 或 模态F | 设置并更新模态速度 | 圆弧插补 |
| **G05** | Feed 或 模态F | 设置默认前瞻速度 | 连续插补（见下文详解） |

### G05 连续插补的前瞻速度

G05连续插补是本系统的核心功能，每个轨迹点都可以有独立的**前瞻速度**。

#### 前瞻速度的作用

```
轨迹点:     P1 -----> P2 -----> P3 -----> P4
前瞻速度:   F5.0      F8.0      F3.0      F5.0
                ↑          ↑          ↑
           控制器根据前瞻速度进行速度规划
           实现平滑的加减速过渡
```

#### 前瞻速度的继承规则

1. **G05行的F参数**：作为该轨迹的默认速度
2. **轨迹点的F参数**：覆盖该点及后续点的速度
3. **未指定F的点**：继承上一个点的速度
4. **完全未指定F**：使用程序的默认Feed速度

#### 示例

```gcode
; Feed: 5.0                    ; 程序默认速度

G05 L"Path1" F6.0              ; G05默认速度=6.0
     X10 Y0 Z10                ; 继承6.0
     X20 Y5 Z10 F8.0           ; 使用8.0，后续继承8.0
     X30 Y0 Z10                ; 继承8.0
     X40 Y5 Z10 F4.0           ; 减速到4.0（精细区域）
     X50 Y0 Z10                ; 继承4.0
```

速度变化曲线：
```
速度
  8 |        ****
  6 |   *****    ****
  4 |                 *****
  2 |
  0 +---+---+---+---+---+---> 位置
     P1  P2  P3  P4  P5
```

## 指令列表

### 运动指令 (G代码)

| 指令 | 名称 | 语法 | 说明 | 默认采集 |
|------|------|------|------|----------|
| **G00** | 快速定位 | `G00 X_ Y_ Z_ [F_]` | 点到点快速移动 | 否 |
| **G01** | 直线插补 | `G01 X_ Y_ Z_ [F_]` | 直线轨迹运动 | 是 |
| **G02** | 顺时针圆弧 | `G02 X_ Y_ [I_ J_] [F_]` | CW圆弧插补 | 是 |
| **G03** | 逆时针圆弧 | `G03 X_ Y_ [I_ J_] [F_]` | CCW圆弧插补 | 是 |
| **G04** | 暂停 | `G04 P_` | 暂停指定时间(ms) | - |
| **G05** | 连续轨迹 | `G05 [L"name"] [F_] {points}` | 多点连续插补 | 是 |

### 坐标系指令

| 指令 | 名称 | 语法 | 说明 |
|------|------|------|------|
| **G90** | 绝对模式 | `G90` | 切换到绝对坐标模式 |
| **G91** | 相对模式 | `G91` | 切换到相对坐标模式 |
| **G92** | 设置坐标 | `G92 X_ Y_ Z_` | 设置当前位置为指定值 |

### 同步采集控制 (M代码)

| 指令 | 名称 | 语法 | 说明 |
|------|------|------|------|
| **M50** | 开始采集 | `M50` | 启动同步采集 |
| **M51** | 停止采集 | `M51` | 停止同步采集 |

### 数据管理指令

| 指令 | 名称 | 语法 | 说明 |
|------|------|------|------|
| **M60** | 保存点云 | `M60 [L"name"]` | 保存当前点云数据（异步） |
| **M61** | 清空数据 | `M61` | 清空点云数据 |
| **M62** | 设置保存路径 | `M62 P"path" [Q"prefix"] [T"format"]` | 设置保存目录、前缀和格式 |
| **M63** | 等待保存 | `M63` | 等待所有保存任务完成 |

**M62格式参数 (T)**：
- `csv` - CSV文本格式，最大兼容性
- `ply` - PLY ASCII格式
- `ply_bin` - PLY二进制格式
- `scan` - 紧凑扫描格式（无压缩）
- `scan_lz4` - **默认**，紧凑扫描格式 + LZ4压缩（推荐）
- `scan_zstd` - 紧凑扫描格式 + ZSTD压缩（最高压缩比）

### 程序控制

| 指令 | 名称 | 语法 | 说明 |
|------|------|------|------|
| **M00** | 程序暂停 | `M00 [(message)]` | 暂停等待用户继续 |
| **M30** | 程序结束 | `M30` | 结束程序执行 |

## 详细说明

### G00 快速定位

快速点到点移动，用于空行程。

```gcode
G00 X0 Y0 Z50              ; 使用默认Rapid速度
G00 X100 Y50 F15.0         ; 指定速度（通常不需要）
```

**特点**：
- 使用**Rapid速度**（默认10.0 mm/s）
- **固定不采集**，即使在M50之后
- 适用于空行程移动

### G01 直线插补

直线轨迹运动，最常用的扫描指令。

```gcode
G01 X100 Y0 Z10            ; 使用默认Feed速度或模态F
G01 X200 F8.0              ; 指定速度8.0，更新模态速度
G01 X300                   ; 继承模态速度8.0
```

**特点**：
- 使用**Feed速度**或**模态F参数**
- F参数是**模态**的，设置后持续有效
- 默认开启采集

### G02/G03 圆弧插补

圆弧轨迹运动。G02顺时针，G03逆时针。

**方式1：圆心偏移定义 (I, J)**
```gcode
G02 X100 Y50 I50 J0 F5.0   ; 顺时针圆弧，圆心偏移(50, 0)
G03 X0 Y100 I0 J50         ; 逆时针圆弧（继承上面的F5.0）
```

**方式2：三点定义 (P, Q)**
```gcode
G02 X100 Y0 P50 Q25 F5.0   ; 中间点(50, 25)的三点圆弧
```

**参数说明**：
- `I`, `J` - 圆心相对于起点的偏移
- `P`, `Q` - 圆弧上的中间点坐标
- `X`, `Y` - 圆弧终点
- `F` - 圆弧运动速度（模态）

### G04 暂停

程序暂停指定时间。

```gcode
G04 P1000             ; 暂停1000毫秒
G04 P500              ; 暂停0.5秒
```

### G05 连续轨迹（重点）

多点连续插补，适用于复杂轨迹扫描。**这是本系统最重要的功能**。

#### 基本语法

```gcode
G05 [L"轨迹名称"] [F默认速度]
     X_ Y_ Z_ [F前瞻速度]      ; 轨迹点1
     X_ Y_ Z_ [F前瞻速度]      ; 轨迹点2
     ...
```

#### 完整示例

```gcode
; ========================================
; 变速连续轨迹扫描
; Feed: 5.0
; ========================================

N10 G00 X0 Y0 Z50
N20 G00 Z10

N30 M50                            ; 开始采集

N40 G05 L"VariableSpeed" F5.0      ; 默认速度5.0
     X0 Y0 Z10                     ; 起点，继承5.0
     X20 Y0 Z10                    ; 继承5.0
     X40 Y0 Z10 F8.0               ; 加速到8.0（直线段）
     X60 Y0 Z10                    ; 继承8.0
     X70 Y10 Z10 F3.0              ; 减速到3.0（转角）
     X80 Y20 Z10                   ; 继承3.0
     X90 Y20 Z10 F6.0              ; 恢复到6.0
     X100 Y20 Z10                  ; 继承6.0

N50 M51                            ; 停止采集
N60 M60 L"VarSpeedScan"
N70 M30
```

#### 速度规划示意

```
速度
  8 |          ****
  6 |   ****        ****
  5 | **    **
  3 |              **
  0 +--+--+--+--+--+--+--+--+---> 位置
    P1 P2 P3 P4 P5 P6 P7 P8
```

#### 关键特点

1. **前瞻速度**：每个点的F参数告诉控制器该点的目标速度
2. **速度继承**：未指定F的点继承前一个点的速度
3. **平滑过渡**：控制器根据前瞻速度自动规划加减速
4. **MERGE模式**：内部使用连续插补，运动更平滑
5. **默认采集**：连续轨迹默认开启同步采集

### M50/M51 采集控制

手动控制同步采集的开启和关闭。

```gcode
M50                   ; 开启同步采集
G01 X100 F5.0         ; 采集中运动
G01 X200              ; 继续采集
M51                   ; 停止采集
G00 X0                ; 此时不采集
```

**注意**：
- M50和M51应该成对使用
- G00在M50后仍然**不采集**（G00固定不采集）
- M30程序结束会自动停止采集

### M60 保存点云

将当前点云数据保存到文件（异步执行）。

```gcode
M60                   ; 使用自动文件名保存
M60 L"Region1"        ; 指定名称保存
```

**文件命名规则**：
```
{保存目录}/{前缀}_{名称}_{编号}.csv

示例：
./scan_data/scan_Region1_001.csv
./scan_data/scan_Area2_002.csv
```

### M30 程序结束

结束程序执行。

```gcode
M30                   ; 程序结束
```

**自动执行**：
1. 停止采集（如果正在采集）
2. 等待所有保存任务完成
3. 返回空闲状态

## 注意事项

### 速度设置

1. **默认值参考控制器参数**
   - Feed: 5.0 mm/s
   - Rapid: 10.0 mm/s
   - Accel: 25.0 mm/s²
   - 请根据实际机械系统调整

2. **速度不宜过快**
   - 过快的速度可能导致运动失控
   - 建议先用低速测试

3. **F参数是模态的**
   - 设置后持续有效
   - 直到被新的F覆盖

4. **连续插补需要前瞻速度**
   - G05每个点都应设置适当的F值
   - 曲率大的位置应减速

### 采集控制

1. **G00固定不采集**
   - 即使在M50之后，G00也不采集数据
   - 适合用于换行等空行程

2. **M50/M51成对使用**
   - 确保采集正确开启和关闭
   - M30会自动停止采集

3. **G01/G02/G03/G05默认采集**
   - 在M50之后这些指令会自动采集

### 文件保存

1. **异步保存**
   - M60提交后立即继续执行
   - 不会阻塞扫描流程

2. **M61清空数据**
   - 在保存后使用M61清空
   - 为下一段扫描做准备

3. **M30自动等待**
   - 程序结束前自动等待所有保存完成

### 坐标系统

1. **默认绝对坐标**
   - 程序启动默认G90模式

2. **G91相对坐标**
   - 相对于当前位置
   - 适合重复模式

## 快速参考

### 速度参数

```gcode
; 头部定义
; Feed: 5.0        ; 默认进给速度
; Rapid: 10.0      ; 快速定位速度
; Accel: 25.0      ; 加速度
; Decel: 25.0      ; 减速度
```

### 指令速度

| 指令 | 速度来源 | 默认采集 |
|------|----------|----------|
| G00 | Rapid | 否 |
| G01 | Feed/模态F | 是 |
| G02/G03 | Feed/模态F | 是 |
| G05 | 每点F/模态F/Feed | 是 |

### 典型程序结构

```gcode
; 程序头
; Feed: 5.0
; Rapid: 10.0

; 初始化
M62 P"路径" Q"前缀"
G90
G00 X0 Y0 Z安全高度
G00 Z扫描高度

; 扫描
M50
G01/G05 运动指令 F速度
M51

; 保存
M60 L"名称"
M61                 ; 如果还有下一段

; 结束
G00 Z安全高度
M30
```

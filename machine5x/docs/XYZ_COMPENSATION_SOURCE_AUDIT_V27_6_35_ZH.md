## 明确不应补偿的内容

| 内容 | 保持原始的原因 |
|---|---|
| 光栅 MPOS、ENCODER、TABLE 锁存值、位置 UI 的反馈通道 | 这是实际测量，不是待修正的命令；再补偿会制造虚假的位置数据。 |
| 点云重建、单球拟合、17 参数标定的测量值、实际姿态 FK | 必须以真实反馈重建；运动目标可以补偿，测量链不能二次处理。 |
| DATUM、回零 SetMpos(0)、原始校准网格、A/B 的已计算 DPOS | 它们建立基准或用于验证补偿，叠加运行表会污染标定与验证。 |
| C/B、旋转机械偏移、G92 工件偏移、I/J/K、TCP 偏置 | XYZ 定位表只适用于 XYZ 关节位置；在上述参数上加表不符合映射定义。 |
| 持续速度 JOG | 没有最终物理位置目标；保留原始速度运动，停止后不自行移动到“补偿终点”。有限寸动走补偿相对定位。 |
| 停止、急停、复位、硬件采集触发、通信和诊断读取 | 这些不是位置目标；不改变原有紧急停止或采集协议。 |

## 架构与不变量

```text
UI / G-code / Stage-2 / 球面采集 / RTCP 名义目标
        ↓（G92、坐标解析、RTCP 逆解在前）
ZmcController：确认回零、运动所有权和起点
        ↓
axiscomp：按轴／方向插值；长路径按表节点分段
        ↓
实际 float DPOS 命令的范围、方向、速度、加减速与队列检查
        ↓
ECI3808 SDK（只转换一次）

MPOS / ENCODER / TABLE → 原有测量与重建链（不经过补偿表）
采表 / 测速 / DPOS 诊断 / A-B → RawDpos 入口（不经过运行补偿）
```

`desired_mpos_mm → required_dpos_mm` 是直接映射，不能再把 correction 列额外相加。
正／反方向表独立使用，不取平均。禁止超范围外推、边界夹紧、异常静默退回 RAW。
启用状态、表和参数不会在实际运动／采样任务或待发队列中途替换；GUI 还封锁完整 Stage-2 自动采集流程的空闲间隙。
运行表不持久化为“下次启动自动启用”；断开、回零或 XYZ 轴配置写入会撤销启用。

## 必须保留的适用边界

X/Y 表来自单调扫描，Z 表来自旧版逐点预加载。程序保留该差异；没有将 Z 的 manifest 改成单调扫描。
执行层不暗中插入 Z ±2 mm 预加载，因为这会改变上层已经检查过的路径。采用 Z 表执行普通计划目标时，必须显式勾选历史条件差异确认；**此选项启用的是映射代码，不表示重新完成了 Z 的不同运动历史验证**。
连续轨迹另有独立确认开关；其静态补偿并非速度前馈、伺服整定或动态跟随补偿。补偿后的 G93 子段仍要通过原规划器的时间可行性检查，可能因必须减速而被拒绝，不能承诺与静态表同时满足任意 G93 时间。
方向分支切换如要求 DPOS 朝名义运动的反方向跳动，会拒绝执行并提示重新建立接近条件；不会通过隐藏回程或删除安全检查来“强行成功”。

# V27.6.9 标定Tab操作流程

## 1. 初步手眼标定
本页就是原两阶段方案的Stage-1。操作者人工改变B/C并用XYZ把固定标准球重新找回线激光视场，采集多个静止姿态。
求解时机床11项几何误差暂固定为名义0，只估计手眼6DoF和固定球心3D，共9状态，要求rank 9/9。

成功条件不是“组数够”而是：
- 至少8个独立姿态，建议12~20；
- B和C都要有独立正/负变化与交叉组合；
- state rank=9/9；
- Stage-1球面RMS和condition通过质量门限。

阶段1通过后自动跳转到运动学标定。

## 2. 运动学标定
本页使用阶段1得到的手眼+固定球心作为导航初值，生成D-optimal五轴姿态。
完成训练集后求解完整Physical17。单未知球对17物理参数存在3D平移gauge，因此17个物理参数的数据秩为14；含未知球心的20状态秩为17。

最终结果必须再使用本页Stage-3独立验证。验证姿态与训练姿态保持B/C间隔，验证数据保存在独立hold-out集合，不重新优化17参数，也不重新拟合固定机床球心。

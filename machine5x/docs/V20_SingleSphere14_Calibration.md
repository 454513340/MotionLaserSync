# V20：19.05 mm 单球条件下的五轴—线激光 14 维联合标定

## 1. 目标与结论边界

本模块面向以下实际条件：

- 五轴结构：`X → Y → Z → C → B`；
- C、B 控制器角度方向沿用 V19：数学右手角分别为 `-Ccontroller`、`-Bcontroller`；
- 线激光：scanCONTROL LLT2950-50/BL，输出传感器坐标中的二维轮廓点
  \(p^S=[x_S,0,z_S]^T\)；
- 标定件：一个固定在工作空间中的直径 19.05 mm 标准球，半径
  \(R=9.525\ \mathrm{mm}\)；
- 球心在机床坐标中的位置未知；
- 没有额外的末端三维平移基准。

在这些条件下，传统物理参数

\[
11\ \mathrm{PIGE}+6\ \mathrm{DoF\ hand\mbox{-}eye}=17
\]

存在三个严格的平移规范自由度。仅增加轮廓数量、B/C 姿态数量或反复进行
“手眼→PIGE→手眼”优化，不能使 17 个物理量唯一化。

因此 V20 不输出一组伪装成物理真值的 17 参数，而是固定一个明确规范，辨识
**全部 14 个由单球数据支持的独立参数**。这 14 个参数足以建立随 XYZCB 变化的
传感器点到统一标定坐标系的复合变换，用于相对点云重建、跨姿态拼接和误差补偿研究。

如果以后获得三个独立平移约束，可以在此结果基础上恢复传统的四项旋转轴位置
PIGE 与三项手眼平移的物理分解。

---

## 2. 14 维规范的定义

### 2.1 规范选择

V20 使用“传感器零位原点规范”：

1. 在 `XYZCB = 0` 时，将线激光传感器光学坐标原点定义为标定坐标系原点；
2. 手眼平移固定为
   \[
   t_{ES}^{gauge}=[0,0,0]^T；
   \]
3. B、C 平均轴线的位置改为相对于该原点的四个有效法向偏置；
4. 手眼旋转保留为三个可辨识参数。

这是一种坐标规范，不是假设真实传感器安装平移为零。真实手眼平移的信息已经被
吸收到四个有效轴线位置和固定球心坐标中。

### 2.2 参数表

| 序号 | JSON/C++ 名称 | 单位 | 含义 |
|---:|---|---|---|
| 1 | `Sxy` | rad | X、Y 实际运动方向的垂直度误差 |
| 2 | `Sxz` | rad | X、Z 实际运动方向的垂直度误差 |
| 3 | `Syz` | rad | Y、Z 实际运动方向的垂直度误差 |
| 4 | `C_offset_u_effective` | mm | C 平均轴线在其法平面第一基方向上的有效位置 |
| 5 | `C_offset_v_effective` | mm | C 平均轴线在其法平面第二基方向上的有效位置 |
| 6 | `C_tilt_x` | rad | C 轴方向倾斜分量 |
| 7 | `C_tilt_y` | rad | C 轴方向倾斜分量 |
| 8 | `B_offset_u_effective` | mm | B 平均轴线在其法平面第一基方向上的有效位置 |
| 9 | `B_offset_v_effective` | mm | B 平均轴线在其法平面第二基方向上的有效位置 |
| 10 | `B_tilt_x` | rad | B 轴方向倾斜分量 |
| 11 | `B_tilt_z` | rad | B 轴方向倾斜分量 |
| 12 | `handeye_rx` | rad | 传感器相对零位末端的旋转向量 X 分量 |
| 13 | `handeye_ry` | rad | 传感器相对零位末端的旋转向量 Y 分量 |

其中 1–3、6–7、10–11 是七个物理角度型 PIGE；12–14 是可辨识的手眼旋转；
4–5、8–9 是规范化后的有效位置项，不能在没有外部三维平移基准时直接报告成
传统物理位置 PIGE。

## 3. 观测方程

设第 \(i\) 个静态记录姿态为

\[
q_i=[X_i,Y_i,Z_i,C_i,B_i]。
\]

线激光轮廓中的第 \(j\) 个球面点为

\[
p_{ij}^S=[x_{ij},0,z_{ij}]^T。
\]

14 维复合运动学给出

\[
p_{ij}^{G}=T_{GS}(q_i;\theta_{14})p_{ij}^{S}，
\]

其中 \(G\) 是上述规范化标定坐标系。固定球的球心
\(c^G=[c_x,c_y,c_z]^T\) 不需要预先知道，而是作为三个 nuisance 参数一起求解。

每个原始轮廓点直接建立点到球面残差：

\[
r_{ij}=\left\|p_{ij}^{G}-c^G\right\|-9.525。
\]

最终求解：

\[
\min_{\theta_{14},c^G}\sum_{i,j}\rho(r_{ij})，
\]

其中 \(\rho\) 为 Huber 鲁棒损失。算法不要求先从每条轮廓估计球心；原始轮廓点
保留了更多几何信息。单轮廓圆拟合只用于初始化、找球和闭环居中。

---

## 4. 单轮廓球心估计

传感器激光平面设为 \(y_S=0\)。已知球半径 \(R\)，轮廓圆为

\[
(x-c_x)^2+(z-c_z)^2=\rho^2。
\]

拟合 \(c_x,c_z,\rho\) 后：

\[
|c_y|=\sqrt{R^2-\rho^2}。
\]

`fitSphereCenterInSensor()` 返回：

- 球心 \([c_x,\pm c_y,c_z]\)；
- 截面圆半径；
- 圆拟合 RMS。

`centerYSign` 必须按实际球位于激光平面的哪一侧固定。不要在同一组数据中任意改变符号。

为避免 \(c_y\approx0\) 时误差放大，姿态规划默认采用

\[
|c_y|=0.4R=3.81\ \mathrm{mm}。
\]

## 5. 姿态设计

### 5.1 为什么不能只做均匀 B/C 网格

仅在 `B=C=0` 或始终把球放在完全相同的传感器坐标，会导致 Jacobian 列高度相关。
V20 从候选姿态中计算 17 状态（14 个目标参数＋3 个球心参数）的局部信息矩阵。
随后先用 Schur 补消去未知球心：

\[
H_{eff}=H_{tt}-H_{tn}H_{nn}^{-1}H_{nt}，
\]

再采用贪心 D-optimal 方法最大化

\[
\log\det(H_{eff}+\lambda I)。
\]

因此姿态选择专门优化 14 个目标参数，而不是为了把未知球心测得更准。选完后再按
B/C 旅行距离重新排序；成员集合不变。

### 5.2 默认候选范围

默认规划配置：

- \(B\in[-50^\circ,50^\circ]\)，候选步长 15°；
- \(C\in[-70^\circ,70^\circ]\)，候选步长 20°；
- 球心目标 \(x_S\in\{-5,0,+5\}\ \mathrm{mm}\)；
- 球心目标 \(z_S\in\{88,95,102\}\ \mathrm{mm}\)；
- 球心目标 \(y_S=\pm3.81\ \mathrm{mm}\)；
- 记录姿态数：42；
- 同一 B/C 组合最多记录两个不同视场位置；
- 同时包含单旋转轴激励和 B/C 耦合激励。

该范围留在 LLT2950-50/BL 标准量程中央区域，避免靠近视场边界。

### 5.3 规划 XYZ 只是种子

`optimized_pose_plan.csv` 中的 XYZ 是根据当前参数估计预测的初值，**不得直接作为
无人值守运动指令**。实际机床的未建模误差、软限位、夹具和碰撞空间均不在规划器中。

正确执行方式：

1. 先保持球仍在视场内，以不大于 5° 的小步改变 B/C；
2. 每一步重新采一条轮廓并拟合球心；
3. 调用 `recommendXYZRecentering()` 获得一个有长度上限的 XYZ Newton 修正；
4. 执行小修正后重新采集；
5. 直到球心到目标的误差满足阈值，再记录正式轮廓和实际 XYZCB；
6. B/C 大跨度运动重复上述过程，而不是一次跳到终点。

闭环修正的局部模型为

\[
\Delta c_S\approx J_{XYZ}\Delta q_{XYZ}，
\]

因此

\[
\Delta q_{XYZ}=J_{XYZ}^{-1}(c_{S,target}-c_{S,measured})。
\]

代码会把一步修正的欧氏长度限制在调用方给定的 `maxStepMm` 内。

## 6. 推荐的真实采集流程

### 阶段 A：准备

1. 将直径 19.05 mm 标准球刚性固定在工作空间中，整个数据集期间不得移动；
2. 将 LLT2950-50/BL 刚性安装到 B/C 末端；
3. 清洁球面，设置稳定曝光，关闭会改变坐标尺度的自动处理；
4. 记录球直径来源和不确定度；
5. 建立只包含球面的分割规则，去除夹具、背景和球边缘异常点。

### 阶段 B：示教零位参考

1. 令 B=C=0，选择安全 XYZ；
2. 手动把球截面移到视场中央，建议 \(z_S\approx95\ \mathrm{mm}\)；
3. 使拟合出的 \(|y_S|\) 接近 3–5 mm，而不是让激光面恰好穿过球心；
4. 保存示教 XYZCB 和拟合球心；
5. 用该种子生成 D-optimal 姿态表。

### 阶段 C：采集 42 个记录姿态

每个目标姿态：

1. 检查目标 B/C、预测 XYZ 是否在软件限位和碰撞包络内；
2. 按小角度步长接近；
3. 进行闭环 XYZ 找球；
4. 球面有效点建议至少 20–30 个，横跨截面直径的 70%–90%；
5. 拟合圆 RMS 过大、截面过短、饱和或明显多路径时不记录；
6. 记录最终稳定后的实际 `X,Y,Z,C,B`，不要记录计划值；
7. 每个姿态可连续采 5–20 条轮廓，用于估计重复性；可先平均，也可全部送入求解器并给同一姿态分配独立 `profile_id`。

### 阶段 D：求解

1. CSV 导入；
2. 交替优化：机床 11 个规范参数块与手眼旋转块；
3. 最后必须释放 14 个目标参数和球心，进行统一 LM 精修；
4. 多初值重复，选择鲁棒代价最小且满秩的结果；
5. 对球心 nuisance 参数做 Schur 补，检查目标 Jacobian 为 14/14 满秩。

### 阶段 E：独立验证

至少保留 6–10 个姿态不参加求解。验证：

- held-out 点到球面 RMS；
- 不同 B/C 下拟合球心在规范坐标系中的漂移；
- 正、反方向接近同一姿态的结果差异；
- 分两次重新开机采集后 14 参数的重复性；
- 用一半姿态标定、另一半验证，防止只在标定轨迹上拟合良好。

## 7. CSV 数据格式

必需列：

```text
profile_id,x_mm,y_mm,z_mm,c_deg,b_deg,sensor_x_mm,sensor_z_mm,weight
```

一条轮廓的所有点使用同一个 `profile_id` 和相同的实际 XYZCB。例如：

```csv
profile_id,x_mm,y_mm,z_mm,c_deg,b_deg,sensor_x_mm,sensor_z_mm,weight
1,100.0,120.0,80.0,0.0,0.0,-7.1,91.8,1.0
1,100.0,120.0,80.0,0.0,0.0,-6.5,90.9,1.0
```

`weight` 可省略；存在时必须非负。建议权重按轮廓点质量、饱和、边缘和拟合置信度设置。

V19 类型可通过 `SingleSphere14QtAdapter::fromLaserProfile()` 转换。该适配器不会自动分割球面；
传入的索引区间必须已经只包含标准球点。

## 8. CLI 使用

### 8.1 仅构建便携 CLI

```bash
cmake -S . -B build-ss14 -DSINGLE_SPHERE14_CLI_ONLY=ON -DCMAKE_BUILD_TYPE=Release
cmake --build build-ss14 --config Release
```

该模式不需要 Qt、VTK、ZMC SDK 或 LLT SDK。

### 8.2 生成记录姿态表

```bash
single_sphere14_cli plan pose_plan.csv \
  --reference X0,Y0,Z0,0,0 \
  --sphere-center-s 0,3.81,95 \
  --diameter 19.05 \
  --count 42 \
  --b-range "-50,50,15" \
  --c-range "-70,70,20" \
  --xyz-limits "Xmin,Xmax,Ymin,Ymax,Zmin,Zmax"
```

这里 `X0,Y0,Z0` 是示教参考位置。`--xyz-limits` 应替换成真实软件限位；还可通过
`--sensor-z-range`、`--sensor-x-half-width`、`--target-x`、`--target-z` 和
`--target-y-ratio` 收紧传感器中央有效区域。输出 XYZ 仍只作为闭环找球种子。

### 8.3 标定

```bash
single_sphere14_cli calibrate captured_profiles.csv result.json \
  --diameter 19.05 \
  --center-y-sign 1 \
  --alternating 8 \
  --block 18 \
  --joint 90 \
  --multistart 3
```

成功结果必须同时满足：

- `success = true`；
- `observability.rank = 14`；
- `observability.expected_rank = 14`；
- 残差与独立验证符合实验精度目标；
- 多初值结果一致。

不能只根据 RMS 很小判断成功。

## 9. 标定结果如何用于点云

对于任意实际五轴姿态 \(q\)，调用：

```cpp
const auto T = SingleSphere14Model::sensorToGaugeMachineTransform(q, params);
```

或直接：

```cpp
Vec3d pGauge = SingleSphere14Model::mapSensorPoint(q, pSensor, params);
```

得到的是传感器点在规范化标定坐标系 \(G\) 中的坐标。

因为绝对三维平移没有被单球数据确定，\(G\) 与控制器传统 MCS 之间仍可能相差一个固定平移。
这不影响：

- 同一数据集不同 B/C 姿态的点云重合；
- 尺寸、圆度、平面度、相对距离；
- 建立在工件自身基准上的坐标；
- 以后通过一个工件基准点/平面补上固定平移。

如果要把结果解释成传统四项旋转轴位置 PIGE和真实手眼平移，必须增加三个独立平移约束，
不能从本 JSON 中强行拆分。

## 10. 仿真结果

当前示例仿真：

- 标准球直径：19.05 mm；
- D-optimal 记录姿态：42；
- 每条轮廓：25 点；
- 目标有效秩：14/14；
- 最小缩放奇异值：约 0.0295；
- 缩放条件数：约 5755；
- 无噪声恢复达到数值精度；
- 代表性含噪仿真球面残差 RMS：约 2.67 μm；
- 8 次 C++ 含噪重复均为 14/14 满秩，残差 RMS 约 2.53–2.95 μm。

这些数值用于验证模型与算法，不是 LLT2950-50/BL 在真实球面、真实反射和真实机床环境下的
保证精度。真实实验还会受到球圆度、表面反射、激光系统误差、XYZ/BC 位置相关误差、温漂、
时间同步和轮廓分割的影响。

本次 Monte Carlo 中相对薄弱的参数是 B 轴某些倾斜分量和三项手眼旋转；因此最终姿态必须
覆盖较大且不对称的 B/C 组合，并覆盖多个传感器 X/Z 位置。

---

## 11. 验收与拒绝条件

建议至少满足：

1. 有效秩为 14/14；
2. 最小奇异值没有因删去少量轮廓而骤降；
3. 多初值结果在预定容差内一致；
4. held-out RMS 与训练 RMS 接近；
5. 同一球心在规范坐标系中的跨姿态漂移无明显 B/C 周期趋势；
6. 正反向接近差异不显著；
7. 参数在重复采集中的标准差可接受。

以下情况应拒绝结果：

- 只使用 B=C=0 或只有单一旋转轴的小范围姿态；
- 球面分割包含夹具或背景；
- 截面弧过短；
- 球心始终位于完全相同的传感器坐标；
- 依赖视场边缘；
- 把规划 XYZ 当作真实机器指令而没有闭环重居中；
- `rank < 14`；
- 只因残差很小就报告成功。

## 13. 实机运动边界

本模块不自动执行机床运动。姿态计划不包含夹具、防撞、线缆扭转、硬件急停、伺服报警和
真实软限位模型。实机采集应在完成离线仿真、单步验证和碰撞包络检查后，由具备机床操作资质的
实验室人员低速执行；保持急停可用，并禁止人员进入运动包络。
